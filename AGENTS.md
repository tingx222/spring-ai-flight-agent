# Project collaboration

Read CONTRIBUTING.md and README.md before making changes.
The user authorizes committing and pushing each completed module to origin after appropriate validation and a secret/diff review. Do not force-push, publish credentials, or claim incomplete modules are complete.
Preserve upstream licenses and explain extensions to the official flight-booking example.
Deliver working Java business flows with UI, authorization, error handling and appropriate tests; keep learning documentation in sync.
Never commit local backups, IDE run configurations, logs, database dumps or dependency caches.
